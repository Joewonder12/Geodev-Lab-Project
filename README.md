# Geodev-Lab-Project(My Project Brief)

## The question
Which farm settlements in Kwara North (Edu and Patigi LGAs) sit inside the
seasonal drawdown floodplain of the Kainji/Niger reservoir, yet have no
all-season road connection to Ilorin?

## The data I need
- Ward & settlement boundaries — GRID3 — https://data.grid3.org
- Settlement/building extents — GRID3 — https://data.grid3.org
- Seasonal surface water extent (reservoir drawdown) — JRC Global Surface Water — https://global-surface-water.appspot.com/download
- Roads (paved vs unpaved) — OpenStreetMap via Geofabrik (Nigeria extract) — https://download.geofabrik.de/africa/nigeria.html
- Elevation — Copernicus GLO-30 DEM via OpenTopography — https://portal.opentopography.org
- LGA administrative boundaries (Edu, Patigi) — GRID3 — https://data.grid3.org
- Reservoir/dam operating context — Nigeria Hydrological Services Agency (NIHSA) — https://nihsa.gov.ng
